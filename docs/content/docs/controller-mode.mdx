---
title: Focus navigation
description: Triage sessions with On radar, Next, Done, and optional auto-advance.
---

**Focus navigation** helps you triage several agent sessions without losing
your place. Add important conversations to **On radar**, then use the controls
beside the conversation to move through the queue.

## When to use it

- Put long-running or attention-heavy sessions **On radar**.
- Use **Next** to mark the current session handled and open the queue's new
  first item.
- Use **Done** when a session no longer belongs on radar.
- Turn on **Auto-advance** to start a short countdown after you reply or resolve
  an input request. Choose **Stay** to cancel it.

The focus panel remains available for conversations that are not on radar, so
you can jump to the next queued session or add the current conversation.

## Keyboard shortcuts

Desktop focus actions have **user-customizable** keyboard shortcuts. The panel
shows the current bindings for **Next**, **Stay**, **Done**, and
**Auto-advance**. Mobile keeps the controls compact and does not show shortcut
chips.

## Auto-advance

When auto-advance is enabled and a countdown starts, the same focus panel shows
the remaining time and the controls you need:

- **Stay** — hold focus where it is.
- **Next** — advance immediately.

The countdown is scheduled whenever you're "done with the current session for
now": after sending a message, clicking **Allow** on a tool-approval card, or
submitting structured input. **Deny** keeps you on the current session. If
another qualifying action happens during a countdown, the timer restarts
instead of creating a second countdown.
